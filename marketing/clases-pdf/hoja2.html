Clase 2 · La terminal, sin miedo

Tu misión: usar la terminal para moverte
y crear una carpeta, solo con comandos.

¿Qué es una terminal?

Otra forma de pedir lo mismo que ya haces con el mouse. Nada de magia.
Siempre tiene su equivalente: ver el contenido de una carpeta en Dolphin = ls en la terminal.

Los comandos que necesitas

ComandoQué haceCon el mouse sería…
pwdMuestra dónde estásLa barra de ruta
lsLista lo que hayVer el contenido
cd carpetaEntra a una carpetaDoble clic
cd ..Vuelve atrásLa flecha atrás
mkdir nombreCrea una carpetaNueva carpeta
clearLimpia la pantalla—
exitCierra la terminalLa X

Trucos que salvan

  • Tab completa el nombre solita. Escribe cd Doc + Tab y aparece.
  • Flecha ↑ repite el último comando.
  • Mirar no rompe nada. Explorar el sistema es seguro.

Practica

1. Abre Konsole.
2. Escribe pwd — ¿dónde estás?
3. Escribe ls — ¿qué hay?
4. Entra a tu carpeta con cd.
5. Crea una carpeta nueva con mkdir mi-carpeta.
6. Compruébalo abriendo Dolphin.
